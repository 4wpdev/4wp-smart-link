# 4WP Smart Link 1.4.0

**Published:** 2026-09-16  
**WordPress.org:** https://wordpress.org/plugins/4wp-smart-link/

## What it does

4WP Smart Link adds clickable Cover / Group / Column links (and lightbox options) in Gutenberg and Query Loop—without nested `<a>` tags.

## Version 1.4.0 — what is new

- **Smart Image Gallery** in the Document sidebar: stats, **Enlarge for all**, **Organize in lightbox** for body Image blocks.
- Page lightbox gallery works more reliably with body images (including copied/foreign attachment URLs).
- Image **captions** show under the enlarged photo in the lightbox.
- Fixes Interactivity crashes when extending core lightbox `showLightbox` / `setButtonStyles`.
